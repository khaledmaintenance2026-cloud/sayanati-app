# صيانتي — تطبيق الصيانة والإنتاج والسلامة

تطبيق Flutter حقيقي (وليس تصميمًا فقط) يطبّق سير العمل الكامل لثلاثة أقسام:
الصيانة، الإنتاج، والسلامة، بحسب المواصفة المتفق عليها.

## الوضع الحالي

- الواجهات وكل منطق سير العمل **حقيقي ويعمل فعليًا**: رفع بلاغ، تعيين فني،
  حساب مدة الإصلاح تلقائيًا، إغلاق بلاغ، تسجيل باتشات الإنتاج، طلب
  تصاريح السلامة واعتمادها.
- البيانات حاليًا **محلية داخل الجهاز** (ذاكرة مؤقتة) للتجربة الفورية —
  لم يُربط بعد بخادم/قاعدة بيانات حقيقية أو بواتساب. عند توفر مشروع
  Firebase الخاص بكم، راجعوا `lib/services/firebase_bootstrap.dart`
  للخطوات (تستغرق دقائق ولا تحتاج تعديل الشاشات).

## كيف تحصلون على ملف APK جاهز للتثبيت

هذا المشروع مُجهَّز ببناء تلقائي عبر GitHub Actions (`.github/workflows/build-apk.yml`)
— يبني APK في السحابة بدون تثبيت أي برنامج على جهازكم. اتبعوا الخطوات:

1. أنشئوا حسابًا مجانيًا على https://github.com إن لم يكن لديكم واحد.
2. من الصفحة الرئيسية اضغطوا **+** أعلى يمين الصفحة ثم **New repository**،
   اختاروا اسمًا (مثلاً `sayanati-app`)، واتركوا باقي الخيارات كما هي، ثم
   **Create repository**.
3. في صفحة المستودع الجديد اضغطوا **uploading an existing file** (أو
   Add file → Upload files)، ثم اسحبوا **كل محتويات هذا المجلد** (وليس
   المجلد نفسه) إلى الصفحة، وانتظروا اكتمال الرفع، ثم اضغطوا
   **Commit changes**.
4. اذهبوا لتبويب **Actions** أعلى الصفحة — سيبدأ بناء تلقائي باسم
   "بناء تطبيق صيانتي (Android APK)" (يستغرق ٥ إلى ١٠ دقائق تقريبًا).

بعد ذلك، أي تعديل لاحق على الكود ثم رفعه لنفس المستودع سيُعيد بناء APK
جديد تلقائيًا بنفس الطريقة.

## كيف تُثبّتونه على الجوال مباشرة (الطريقة الأسهل)

بعد اكتمال أول بناء بنجاح، سيظهر رابط تحميل ثابت لا يتغيّر (مناسب لفتحه
من متصفح الجوال نفسه، بدون فك ضغط):

```
https://github.com/<اسم_المستخدم>/<اسم_المستودع>/releases/tag/apk-latest
```

1. افتحوا هذا الرابط من متصفح الجوال (استبدلوا الاسمين بمستودعكم الفعلي
   — تجدونه أعلى صفحة المستودع، أو من تبويب **Releases** في الصفحة الرئيسية).
2. اضغطوا على `app-release.apk` (أو `app-debug.apk` إن لم يظهر) لتحميله
   مباشرة على الجوال — بدون Zip وبدون تسجيل دخول إن كان المستودع عامًا (Public).
3. افتحوا الملف المحمَّل من إشعارات التحميل أو تطبيق الملفات. عند أول
   تثبيت سيطلب أندرويد تفعيل "السماح بالتثبيت من هذا المصدر" — وافقوا،
   ثم أكملوا التثبيت.

نفس الرابط يبقى صالحًا ويتحدّث تلقائيًا مع كل بناء جديد.

### الطريقة البديلة (Artifacts)

من تبويب Actions → افتحوا التشغيلة المكتملة → **Artifacts** أسفل الصفحة
→ حمّلوا `sayanati-app-apk` (يحتاج تسجيل دخول GitHub دائمًا، ويأتي كملف
مضغوط zip يحتاج فك ضغط قبل التثبيت) — مفيدة إن كان المستودع خاصًا
(Private) أو أردتم النسختين معًا في مكان واحد.

## نسخة آيفون

جاهزة من ناحية الكود (`flutter build ios` يعمل بنفس المشروع بدون أي تعديل)،
لكنها تحتاج حساب Apple Developer (اشتراك سنوي) للتوقيع الرسمي — لا توجد
طريقة تقنية للتحايل على هذا الشرط من آبل. عند توفره، أخبرونا لإضافة خطوة
بناء iOS إلى نفس البناء التلقائي.

## هيكل المشروع

```
lib/
  models/       نماذج البيانات (بلاغ، فني، باتش، تصريح عمل)
  services/     منطق التطبيق والبيانات (app_state.dart) + أدوات تنسيق عربية
  theme/        ألوان وخط الهوية البصرية
  widgets/      مكوّنات مشتركة (أزرار، شارات، بطاقات KPI)
  screens/      شاشات الأقسام الثلاثة + الرئيسية
```
